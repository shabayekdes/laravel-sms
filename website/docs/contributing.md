# Contributing

Issues and pull requests are welcome on [GitHub](https://github.com/shabayekdes/laravel-sms). Run the tests before you open a pull request:

```bash
composer test
```

Code style follows the Laravel preset and is checked by StyleCI.

## Documentation

This site lives in the `website/` folder of the repository and is built with [Docusaurus](https://docusaurus.io). To preview a change locally:

```bash
cd website
npm ci
npm start
```

## Security vulnerabilities

If you've found a bug regarding security please mail [esmail.shabayek@gmail.com](mailto:esmail.shabayek@gmail.com) instead of using the issue tracker.
